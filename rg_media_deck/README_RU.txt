RG Media Deck 0.1.6 - програма для Windows 10/11 x64

ОНОВЛЕННЯ ІНТЕРФЕЙСУ
1. Оновлено дизайн: глибокий чорний фон, графітові панелі, контрастні кнопки.
2. Назву медіатеки змінено на «ФАКТАЖ ПРОЄКТУ РАША ГУДБАЙ».
3. Зроблено три великі окремі кнопки PLAY / PAUSE / STOP.
   PLAY запускає обраний файл або продовжує відтворення після паузи.
   PAUSE призупиняє поточне відео.
   STOP зупиняє відео та його звук, у перегляді залишається чорне поле.
4. Велика кнопка «ГУЧНІСТЬ» за одне натискання вимикає/вмикає звук;
   повзунок зберігає останній рівень гучності. Стан запам'ятовується.
5. Швидкість: кнопки − та +, список 0.5x / 0.75x / 1.0x / 1.25x / 1.5x / 2.0x.
   Обрана швидкість зберігається і застосовується до наступного відео.
6. Видалено старі кнопки «ВІДТВОРИТИ ОБРАНЕ» і «ЧОРНИЙ ЕКРАН»,
   підпис про захоплення OBS і опцію циклічного повтору відео.
7. Окремого вікна OBS OUTPUT немає. OBS захоплює область відтворення.

ВСТАНОВЛЕННЯ
- Закрийте попередню версію програми, запустіть RG_Media_Deck_Setup.exe.
- Inno Setup встановлює програму в LOCALAPPDATA/Programs/RG Media Deck.
- Налаштування, папки, обране та гучність залишаються в LOCALAPPDATA/RGMediaDeck.
- Для наступних випусків використовуйте «Налаштування» -> «Перевірити оновлення».
- Не оновлюйте програму під час прямого ефіру.

OBS
Додайте «Захоплення вікна» для головного вікна RG Media Deck та обріжте
картинку до області попереднього перегляду (Alt + мишка у OBS).
Звук захоплюйте джерелом «Захоплення звуку програми» для RG_Media_Deck.exe.
Якщо використовується Desktop Audio, уникайте дублювання звуку.
У разі зміни розміру вікна коригуйте область обрізання.

КЕРУВАННЯ
Ctrl+F - пошук; Ctrl+Enter - PLAY; Ctrl+P - PLAY/PAUSE;
Escape - STOP; F5 - оновити бібліотеку.
Підтримка деяких форматів і швидкостей залежить від кодеків Windows.

РОЗРОБНИКАМ
BUILD_SETUP_WINDOWS.ps1 збирає EXE з Python 3.12/PyInstaller та Setup.exe через
Inno Setup 6; GitHub Actions виконує модульні та GUI self-tests і випускає інсталятор.
