RG Media Deck 0.1.8 - Windows 10/11 x64, встановлення через Setup.exe.

ЩО НОВОГО У 0.1.8
- Кадрування відбувається виключно при малюванні кадру у фіксованій області плеєра.
  Жоден дочірній відеовіджет не масштабується, розмір OBS capture не змінюється.
- Верхній рядок з назвою та кнопками повністю прибраний.
- Шестерня поряд із «В обране»: додати папку, папки, оновити медіатеку,
  автокадрування, налаштування та оновлення програми.

ІНШІ МОЖЛИВОСТІ
- Об'єднана кнопка ▶/Ⅱ. Старт і пауза однією кнопкою.
- Клавіатура: ПРОБІЛ - Play/Pause; Enter - відтворити вибране;
  S або Escape - STOP; M - вимкнути/увімкнути звук;
  стрілки ←/→ - назад/вперед по 5 с (коли фокус не у списку),
  Ctrl+←/→ - перемотування у списку, Shift+стрілки - по 30 с;
  ↑/↓ - гучність (коли фокус не у списку),
  +/− - змінити швидкість, 0 - нормальна швидкість;
  Ctrl+F - пошук, Ctrl+O - додати папку, F5 - оновити;
  Delete - перемістити вибраний файл у кошик Windows (з підтвердженням);
  Z - вкл./викл. автоматичне прибирання чорних полів;
  V - примусовий вертикальний кадр 9:16 для вбудованих портретних відео.
- Контекстне меню (права кнопка миші) на файлі:
  «Видалити файл», «Додати/Прибрати з обраного», «Показати розташування».
- Видалення переміщує файл саме з вихідної папки у КОШИК Windows.
  Перед видаленням є підтвердження. Це захищає від випадкової втрати файлу.
- Вертикальні файли підлаштовуються за висотою плеєра зі збереженням пропорцій.
- Для пейзажного відео з вбудованими чорними полями плеєр вибірково
  аналізує декілька кадрів і підлаштовує сам зміст до розміру плеєра.
  Якщо поля не знайдено, можна увімкнути ручний режим V / контекстне меню.
- Функції звуку і змінної швидкості, попередній перегляд і бібліотека збережені.

ВСТАНОВЛЕННЯ / ОНОВЛЕННЯ
Закрийте програму й установіть RG_Media_Deck_Setup.exe поверх минулої версії.
Далі користуйтеся «⚙» -> «Налаштування та оновлення програми» -> «Перевірити оновлення».
Бібліотека, папки, обране, рівень гучності й швидкість зберігаються
у LOCALAPPDATA/RGMediaDeck, а не в папці EXE.
Не оновлюйте застосунок під час прямого ефіру.

OBS
Джерело «Захоплення вікна» для RG Media Deck обріжте до чорної області плеєра.
Звук - окремий «Захоплення звуку програми» для RG_Media_Deck.exe.
Не дублюйте той самий звук через Desktop Audio.
Збільшення чорних полів масштабуванням змінює КАДРУВАННЯ, а не
співвідношення сторін: вміст не розтягується.
