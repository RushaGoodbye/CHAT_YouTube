RG Media Deck 0.3.2 - Windows 10/11 x64, встановлення через Setup.exe.

НОВЕ В 0.3.2: ЗБІЛЬШЕННЯ ОСНОВНОГО ВІДЕО В СКЛАДЕНОМУ КАДРІ
- Авто-контент: пошук центрального відеоблоку всередині кадру з декоративними написами, верхньою / нижньою шапкою та чорними/кольоровими полями.
- Автоматичне кадрування вмикається тільки коли послідовні незалежні кадри підтверджують ті самі межі. Якщо межі невизначені - показувати повний кадр.
- Відео збільшується виключно всередині ФІКСОВАНОГО плеєра. Розміри вікна, OBS crop, слайдера та кнопок не змінюються.
- Ручний режим: права кнопка миші на відео -> «Виділити основне відео мишею...». Обведіть потрібне відео прямокутником, підтвердіть OK.
- Збереження ручної ділянки окремо для кожного відео. Після повторного запуску цього відео кадр відновлюється.
- У шестерні також є команда ручного виділення відеокадру.
- Звичайне відео можна показати повністю: ПКМ на плеєрі -> «Вписати (повний кадр)».
- Режим «Заповнити» центрує обрізання із збереженням пропорцій.

ЗВЕРНІТЬ УВАГУ
- Втрата декоративної шапки у режимі «Авто-контент» або ручному режимі - очікувана поведінка: вони поза виділеною областю.
- Якщо корисні написи були всередині кадру, обирайте ширшу ручну ділянку або «Вписати».
- Змінюйте налаштування масштабу поза ефіром або після перевірки на вибраному ролику.
- Клавіші: Enter - запустити вибране; Пробіл - пауза/продовжити; S - стоп; M - звук; F1 - довідка; B - мітка; [ / ] - мітки.
- Підказки на файлах (мініатюри) не перемикають поточне відео.

ВСТАНОВЛЕННЯ
Закрийте стару версію й установіть RG_Media_Deck_Setup.exe поверх неї.
Або натисніть ⚙ -> «Налаштування та оновлення програми».
Папки, обране, теги, мітки, звук та індивідуальні кадри зберігаються в LOCALAPPDATA/RGMediaDeck.
Оновлюйте програму тільки поза ефіром.

OBS
Захоплюйте ОСНОВНЕ вікно RG Media Deck й обріжте до плеєра.
Звук - «Захоплення звуку програми» для RG_Media_Deck.exe (без дублювання Desktop Audio).
Область захоплення OBS залишається незмінною при переключенні режимів.
