# RG YouTube Control 0.6.0

## Коментарі - завершений робочий цикл

- Повністю перероблена вкладка «Коментарі».
- Локальна генерація через Ollama / qwen3:8b без YouTube API квоти.
- Структурований quality-gate: ready / skipped / error.
- Причина SKIP або помилки зберігається в SQLite.
- Коментарі на модерації YouTube блокуються від локальної генерації та відповіді.
- Жодного автоматичного схвалення held-for-review.
- Окремий фільтр стану чернетки.
- Стан чернетки показується окремою колонкою.
- Повний текст чернетки читається напряму з SQLite в нижній панелі.
- Лічильники готових, SKIP/помилок та модераційних коментарів.
- Створення перших 20 нових чернеток.
- Перегенерація 20 локально перевірених коментарів.
- Очищення локальних чернеток без змін на YouTube.
- Перехід до наступної готової чернетки для швидкої ручної перевірки.
- Відповідь на вибраний коментар використовує актуальні дані SQLite.
- Відправлені відповіді не видаляються під час очищення чернеток.
- Панель дій рознесена на дві строки, щоб кнопки не обрізались.
- Додані end-to-end тести шляху: генерація -> SQLite -> стан -> UI.
- Оновлення продовжують публікуватись через runner-free GitHub Pages update channel.
